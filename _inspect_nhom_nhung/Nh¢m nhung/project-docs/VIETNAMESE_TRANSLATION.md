## Vietnamese Language Guidelines (Hướng dẫn sử dụng tiếng Việt)

### For Future Development:

**Shopping Cart Terms:**
- Cart = Giỏ hàng
- Checkout = Thanh toán
- Order = Đơn hàng
- Price = Giá
- Discount = Giảm giá
- Total = Tổng cộng

**Product Terms:**
- Product = Sản phẩm
- Category = Danh mục
- Brand = Thương hiệu
- Description = Mô tả
- Details = Chi tiết
- Quantity = Số lượng

**User Actions:**
- Add = Thêm
- Remove = Xóa
- Buy = Mua
- Search = Tìm kiếm
- Filter = Lọc
- Sort = Sắp xếp

**Common Phrases:**
- Free delivery = Miễn phí giao hàng
- Out of stock = Hết hàng
- In stock = Còn hàng
- Best seller = Bán chạy
- New arrival = Hàng mới về
- Recommended = Đề xuất / Gợi ý
